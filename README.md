# Produções de Ana Carolina Vaz

Repositório das produções públicas de Ana Carolina Vaz: índices e painéis, notas técnicas e relatórios, trabalhos acadêmicos e textos de opinião e divulgação.

Site: https://anavazzzz.github.io/portfolioprofissional/

A página inteira está em `index.html`. Para incluir uma produção, copie um bloco `<article class="it">`, ajuste a categoria (`data-cat`), a data, os textos e os links. As contagens do sumário se atualizam sozinhas.
